How Fixipedia works

Catalog first, meaning second, evidence always.

1. Find the record

Look up any waypoint by name, airport, or location.

2. Add the story

Know the origin? Add it and help fill in the map.

3. Explore

Dive into the stories behind the names and see what you discover.

Submit a fix

Add or update a name-origin note.

Submissions open a prefilled GitHub Issue so each name-origin claim can be reviewed before it becomes part of the public archive.

Source standards

Confidence labels keep the archive honest.

Confirmed

Direct source or official documentation names the origin.

Likely

Strong contextual evidence, but no direct naming source yet.

Unverified

A useful lead that needs corroboration before being treated as fact.
